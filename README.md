# HTML Timetable

## Explanation

This project demonstrates how to create a weekly class timetable using an HTML table.

## Problem Statement

Create an HTML webpage that displays a student's weekly class timetable with days, subjects, and break periods.

## Features

* Weekly schedule
* Days and time periods
* Subject names
* Lunch break
* HTML table structure
* Simple beginner-friendly design

## How It Works

The `<table>` element creates the timetable.

The `<tr>` element creates rows.

The `<th>` element creates table headings.

The `<td>` element contains the timetable data.

The `colspan` attribute is used to merge cells for the lunch break.

## Technologies Used

* HTML5

## Program Flow

1. Open the timetable webpage.
2. Display the timetable heading.
3. Display the days and time periods.
4. Add subjects to the table.
5. Add the lunch break.
6. Display the complete weekly timetable.

## Sample Input

Days: Monday to Friday
Subjects: Mathematics, C Programming, Java, English, Data Structures

## Sample Output

A weekly class timetable is displayed in an HTML table.

* `<table>`
* `<tr>`
* `<th>`
* `<td>`
* `colspan`
